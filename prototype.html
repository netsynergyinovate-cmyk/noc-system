        1

        Aktifkan REST API pada Router MikroTik (RouterOS v7)

        Aplikasi membaca beban CPU, RAM, antarmuka, dan sesi PPPoE melalui REST API bawaan RouterOS.

        # 1. Aktifkan service REST API di RouterOS v7 /ip service set www disabled=no port=80 /ip service set www-ssl disabled=no port=443 # 2. Buat grup dengan izin monitoring (read-only) /user group add name=noc-agent policy=read,api,rest,test # 3. Daftarkan user operator pengawas /user add name=noc-monitor group=noc-agent password="StrongSecretPassword123"
        💡 Uji respons REST di terminal: curl -k -u noc-monitor:StrongSecretPassword123 https://10.10.0.1/rest/system/resource
        2

        Konfigurasi SNMP & Redaman Optik pada OLT GPON

        OLT (ZTE C320 / Huawei MA5608T / HSGQ) dihubungkan lewat protokol SNMP v2c untuk monitoring daya RX ONT.

        # 1. Aktifkan SNMP Agent pada OLT snmp-server community nocpublic ro snmp-server host 10.10.0.10 version 2c nocpublic snmp-server enable traps
        ONT pelanggan dengan redaman optik lebih buruk dari -27.0 dBm akan ditandai sinyal kritis.
        3

        Jalankan Collector Engine Backend Go (High-Speed Hub)

        Layanan Go mengumpulkan data tiap 1 detik dan membuka streaming WebSocket di port 8080.

        # Jalankan backend collector di terminal host: npm run backend:dev
        Saat collector aktif, indikator pojok kanan atas dashboard akan berwarna hijau: "Terhubung (1 sampel/detik)".
        4

        Konfigurasi Environment Aplikasi ke Mode Live

        Pindahkan mode simulasi demo ke pembacaan data fisik riil pada file .env.local.

        DASHBOARD_DATA="live" REALTIME_TOKEN_SECRET="kunci-rahasia-hmac-anda" DATABASE_URL="postgres://user:password@localhost:5432/noc_db"
        Jalankan npm run doctor untuk memverifikasi kesiapan database PostgreSQL lokal.
        5

        Daftarkan Perangkat & Pantau Jaringan Secara Live

        Tambahkan router MikroTik dan OLT pertama Anda, seluruh metrik langsung tampil di dasbor.

# Indikator RTO: pisahkan penyebab aplikasi vs MikroTik

## Masalah
Dashboard (`traffic-rto-alert`) dan panel VLAN (`vlan-rto-badge`) menampilkan "MikroTik Tidak Merespons (RTO)" setiap kali sampel trafik berhenti >= 5 s, termasuk saat WebSocket aplikasi ke backend Go putus (mis. BACKEND_URL salah di Coolify). Itu menyalahkan MikroTik untuk masalah di sisi aplikasi.

## Perubahan
- `src/lib/dashboard/staleness.ts`: input `feedLive`, hasil `cause` (`feed` | `router` | `nodata`), `staleShortLabel`, `staleMessage`.
  - feed: WebSocket tidak `live`, jadi status router dari backend dianggap basi.
  - router: backend melaporkan `reachable=false` (RTO sungguhan, dengan `lastError`).
  - nodata: tersambung, router terjangkau, tetapi sampel baru belum datang >= 5 s.
- `noc-dense-dashboard.tsx`, `vlan-pon-traffic-board.tsx`: baca `connection` dari store, teks badge/kartu sesuai penyebab. Testid tetap.
